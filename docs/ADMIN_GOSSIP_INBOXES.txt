Admin gossip inboxes — 13 November 2026

Conference administrators can now read gossip boxes across all ten committees.
The admin page provides All committees, individual committee filters, dismissed
messages, pull-to-refresh, retries and cursor-based older-message loading.
Each RPC page is limited to 100 messages; timestamp/UUID cursors prevent tied
creation timestamps from dropping messages. No sender identity is returned.

Admins have read-only access. Chairs retain their own inbox and status controls.
Delegates retain submission access only. The submission notice now explicitly
states that committee chairs and conference administrators can read messages.
Responses are scoped to the current profile and selected committee, and stale
requests are invalidated when either changes.
