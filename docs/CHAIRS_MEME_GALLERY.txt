Chairs meme gallery — 8 November 2026

A separate Chairs destination appears beside General for attendee chairs.
Chairs may still post to General and their own committee. Only current chairs
can post in Chairs. Conference chairs can view, vote and comment there.
Admins can read and moderate via the organiser dashboard; admin status alone
never grants permission to post. Delegates have no access to Chairs.

Migration: supabase/migrations/202611080003_chairs_meme_gallery.sql.
Existing posts default to chairs_only=false. New private posts have no committee
and chairs_only=true. General/committee RPCs exclude them, including old clients.
Private photos, comments, totals and vote/comment mutations check current access.
An image's former ownership cannot bypass access after switching to delegate.
Upload reservation capacity, hourly post limits and moderation rules are retained.
As with existing galleries, an already-issued image URL expires within 5 minutes.

The admin review component now includes a Chairs filter and labels private posts.
The admin Next.js app has a separate deployment from the mobile web export.
